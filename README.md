# App Marca Pontos

## Objetivo do sistema:
O aplicativo tem por objetivo ser utilizado para marcar a pontuação de jogadores em qualquer tipo de jogo.

## Principais funcionalidades:
- Registrar pontuação de jogadores
- Adicionar e remover jogadores a qualquer momento
- Salvar registros de partidas ao log
- Mostrar partidas salvas no log, mostrando o vencedor
- Limpar partidas salvas ao log
